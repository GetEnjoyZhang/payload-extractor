推荐 · 自己部署一个 Cloudflare Worker（免费，约 2 分钟）：
1. 打开 dash.cloudflare.com → Workers → Create Worker， 部署新 Worker，删除示例代码，点击下方「复制 Worker 代码」→ 粘贴 → Deploy
2. 在此填入 https://你的worker名.你的子域.workers.dev（Worker 详情页可见）
本地一次性使用：node web/tools/proxy.js 8787，填入 http://127.0.0.1:8787。设置仅保存在本机浏览器。
